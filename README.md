## Gambaran umum

Omni-Science menyediakan kumpulan fungsi perhitungan untuk mendukung pembelajaran dan eksplorasi konsep ilmiah. Pengguna dapat menelusuri fungsi berdasarkan kebutuhan serta menyimpan akses ke perhitungan yang sering digunakan.

## Cakupan

- Matematika, fisika, kimia, dan biologi.
- Konversi satuan.
- Pencarian fungsi, riwayat, dan favorit.

## Teknologi dan struktur

HTML, CSS, dan JavaScript; halaman utama `index.html`, logika aplikasi dalam `js/`, serta gaya visual dalam `css/`.

## Menjalankan secara lokal

```bash
git clone https://github.com/lamberthrumpaidus/Omni_Science.git
cd Omni_Science
python -m http.server 8000
```

Buka `http://localhost:8000/` melalui browser. 

## Catatan penggunaan

Hasil perhitungan perlu diverifikasi menggunakan metode dan referensi yang relevan untuk kebutuhan akademik atau profesional yang memerlukan ketelitian tinggi.
